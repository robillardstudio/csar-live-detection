Direction B, refined

Try it on the left. Switch between idle and live, toggle recording mid-session, open Details, and tap a label.

  1. Recording works mid-session. The record switch stays in the session card while live. Turning it on shows a red timer there and a REC badge on the camera, so recording can start at any point.
  2. Details is a session readout. Grouped like a settings screen: Model, Performance, Location, Heading, Session. Values are right-aligned with fixed-width numbers, the coordinates have a Copy button, and the missing compass is a single warning instead of giant monospace text.
  3. Add label is a floating button. It's always there. While live, the sheet attaches the current frame and offers the model's top guesses as one-tap chips. While idle, it saves the label with location only and offers recent labels instead.
  4. Tapping a label shows its actions. Add to, Replace and Delete open inside the row. Replace reuses the same sheet. Delete is undoable from a toast instead of a confirm dialog.
